# MECH DUEL 出招表与连段系统设计（仿街霸 6 · Modern 键盘范式）

> 2026-08-30 · 路线图阶段 5-6 的细化设计蓝图
> **落地状态：已全部实现**（5A/5B/6A/6B 四批完成，selftest [21]-[29] 全过，
> 平衡回归 400 局 52% 带内）。实现与设计的差异见 §2.1 实现注记及各批提交记录。
> 核心适配决策：SF6 的搓招指令（236+K 等）在纯数字键盘上不可行，全面采用 SF6
> **Modern 操作范式**——方向+键位直接出特殊技。深度不靠输入难度，靠资源管理、
> 取消阶梯与攻防择。所有数值为初始设计值，以平衡回归校准为准。

## 一、按键层（Modern 三键布局）

新增 1 个攻击键「重击」，与现有轻斩/光束构成 SF6 式轻/重/射击三攻击键：

| 动作 | P1 | P2 |
|---|---|---|
| 轻斩 | `J` | 小键盘1 |
| 重击（新） | `U` | 小键盘5 |
| 光束 | `K` | 小键盘2 |
| 投技 | `L` | 小键盘3 |
| 超必杀 | `I` | 小键盘4 |
| 防御 | `S` | `↓` |

新动作同步进 `P1_KEYS/P2_KEYS/SEL_ACTS/keyconfig`（重映射自动覆盖）。

**设计取舍：不做蹲防与上下择。** 键盘方向被移动/跳/防御占满，硬加「下」会破坏移动
手感。博弈深度改由四组择承担：打投择（§2.4 投拆）、Drive 择（§3）、角落择（墙崩）、
资源择（OD/超必杀）。这是对键盘现实的诚实适配，不是阉割。

## 二、通用系统（引擎前置 + 仿 SF6 全局机制）

### 2.1 受防硬直（引擎前置，最优先）
现状被防 = 攻击方裸吃全部恢复帧、防守方立即自由 → 帧数据无意义、所有被防攻击
必被惩罚。新增 `BLOCK_STUN = 9`（受防硬直帧）+ 被防推距 2.2px。此后下表所有
「被防 ±帧」才有意义，也是惩罚反击的前提。
**实现注记（5A 落地）**：`BLOCK_STUN = 12`——轻斩被防约攻方 -6、重击约 -12，
比设计值略偏防守方（本作有格挡削血+破防槽，保守起步），后续批次按回归校准；
下表「被防 ±帧」为设计目标值。

### 2.2 惩罚反击 Punish Counter
命中处于出招后摇 / 落空投技硬直 / GUARD BREAK 的对手：伤害 ×1.2 + 硬直 +4 帧 +
强制击倒 + HUD 弹字「PUNISH」。

### 2.3 统一伤害衰减（连段地基）
全连段共用衰减器：每段 -15%、下限 40%。衰减重置条件：受身成功 / 脱离 hit 状态
30 帧 / 被防重置。HUD 连段计数显示 `x HITS（衰减 %）`。

### 2.4 投拆 Throw Tech
防守方在对手 `THROW_HIT_T` 前 6 帧内按投 → 拆投（双方后退 3px，无伤）；同帧双投
自动双拆。拆投后投方 -6 帧不利（拆投本身是择的答案）。

## 三、相位槽 Drive（仿 Drive Gauge）

`DRIVE_MAX = 120`，HUD 6 格。受击 -12 / 被防 -6 / 完美格挡 +25 / 脱战 0.05/帧。
耗尽 → 20 帧疲劳硬直 + 槽清空缓回（0.03/帧）。

| 用途 | 指令 | 消耗 | 效果 |
|---|---|---|---|
| 冲击 Drive Impact | 轻+重同按，蓄力 45 帧自动出手 | 0 | 28 伤击飞；命中贴墙对手 → **墙崩**（贴墙眩晕 40 帧 = Lv3 确认机会）。蓄力中被打即中断 |
| 完美格挡 Perfect Parry | 对手判定帧前 0-4 帧内按防 | 0 | 弹开、攻击方 +5 硬直、回 Drive 25、无 chip |
| 驱动冲刺 Drive Rush | 完美格挡后 / 任意取消窗内双击前 | 1 格 | 高速突进 14 帧；突进中命中 → 该击标记「可取消」，长连段入口 |
| 逆转反技 Drive Reversal | 防御中 →+重 | 2 格 | 弹开并反击 14 伤 |
| OD 强化技 | 方向 + 轻+束同按 | 1 格 | 特殊技强化版（帧数/伤害/弹道增强，见各机甲表） |

## 五、连段系统（取消阶梯与择）

### 5.1 取消阶梯

| 起手 | 命中后可取消 | 被防后可取消 |
|---|---|---|
| 轻斩 | 链轻 / 目标连段 / 特殊技 / 重击 / 光束 / Lv1-3 / 绿冲 | 特殊技 / Lv1-3 |
| 重击 | 特殊技 / Lv1-3 / 绿冲 | Lv1-3 |
| 特殊技 | Lv1-3 / 绿冲 | — |
| 光束命中 | Lv1-3 | — |

与现状的差异：① 现「仅命中可取消」→ **被防也可取消进特殊技/超杀**（攻防转换核心）；
② 新增链轻与目标连段。同帧多指令优先级：Lv3 > Lv2 > Lv1 > OD > 特殊 > 重 > 轻。

### 5.2 确认连段（设计目标值，供 selftest 断言参考）

- GARNET：站轻 → 目标连段（重·击倒）→ Lv1 ≈ 12 + 18 + 30（衰减后）≈ **55**
- AZURE：相位刺 → 轻链×2 → 裂地光刃 ≈ **30**
- VERDANT：藤蔓勾拉 → 前重浮空 → 空中下劈 → Lv1 ≈ **40**
- 目标区间：普通实战连段 25-45 伤；墙崩 → Lv3 确认 ≈ 70+（高资源高回报）

### 5.3 博弈择的深度来源

打投择（投拆后投不再无解）· 冲击择（蓄力被抢断与拆招）· 角落择（墙崩 40 帧眩晕）
· 绿冲择（1 格 Drive 买连段延展）· 资源择（OD 与超杀格数分配）。
